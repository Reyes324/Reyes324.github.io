YouTube 逐字稿生成器

粘贴 YouTube 链接，自动提取字幕并翻译为中文

提取方式： 需启动本地 Python 服务器

使用说明

方式一：本地服务器（推荐，最可靠）

  1. 安装依赖：pip install youtube-transcript-api flask flask-cors
  2. 启动服务器：python3 transcript_server.py
  3. 打开本页面，选择「本地服务器」模式
  4. 粘贴 YouTube 链接，点击「提取字幕」

方式二：CORS 代理（免部署）

  • 选择「CORS 代理」模式，直接使用
  • 通过第三方代理获取 YouTube 页面数据
  • 注意：可能受 YouTube 反爬限制影响

翻译功能

  • 提取字幕后点击「翻译为中文」按钮
  • 使用 MyMemory 免费翻译 API，无需 API Key
  • 支持复制和下载逐字稿
