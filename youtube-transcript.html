YouTube 逐字稿生成器

粘贴 YouTube 链接，自动提取字幕并翻译为中文

提取方式： 通过代理直接提取，无需安装

使用说明

方式一：在线提取（推荐，最简单）

  • 默认选中，直接粘贴链接即可使用
  • 通过 CORS 代理提取 YouTube 字幕，无需安装
  • 注意：部分视频可能受 YouTube 限制影响

方式二：本地服务器（最可靠）

  1. 安装依赖：pip install yt-dlp flask flask-cors
  2. 启动服务器：python3 transcript_server.py
  3. 选择「本地服务器」模式，粘贴链接提取

阅读模式

  • 将碎片字幕按时间间隔合并为段落，方便阅读
  • 自动检测说话人标注，格式化为对话样式

翻译功能

  • 提取字幕后点击「翻译为中文」按钮
  • 使用 MyMemory 免费翻译 API，无需 API Key
  • 支持复制和下载逐字稿
